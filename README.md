# jobsaggregator

Читает вакансии из публичных Telegram-каналов (через веб-превью `t.me/s/<канал>`, без аккаунта),
отсеивает лишнее, извлекает поля и складывает в одну таблицу (Google Sheets или CSV) без дублей.

Поток: каналы → префильтр → извлечение (правила; AI с этапа 5) → дедупликация → запись строк → сохранение состояния.

## Быстрый старт (локально)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest -q
jobagg --dry-run            # прочитать каналы, ничего не записывать
jobagg                      # записать в out/jobs.csv (store.type: csv)
jobagg --dump-posts 60      # сохранить сырые посты в out/posts_*.jsonl
jobagg --store sheets       # писать в Google Sheets (нужны SHEET_ID и GOOGLE_SA_JSON)
```

## Закрытые каналы (Telegram API)

Запуск с твоего компьютера, а не с GitHub Actions: у сессии должен быть постоянный IP.

1. Получить `api_id` и `api_hash` на https://my.telegram.org → API development tools.
2. `cp .env.example .env` и заполнить `TG_API_ID`, `TG_API_HASH`.
3. `pip install -e ".[telegram]"` и `python scripts/tg_login.py`: вход по коду из Telegram,
   сессия сохраняется в `tg.session` (в git не попадает). Скрипт печатает каналы с id.
4. Нужные каналы вписать в `config.yaml` → `telethon.channels`.
5. Проверка: `jobagg --dry-run`.

`tg.session` даёт полный доступ к аккаунту: не пересылай его и не клади в репозиторий.

## Настройка

Всё в `config.yaml`: каналы, ключевые слова префильтра, режим AI, порог дедупликации, хранилище.

## Правила

- **Дубли.** Точный дубль (та же ссылка на вакансию; иначе тот же контакт и должность; иначе
  должность + компания + город) пропускается. Похожая должность в той же компании за 30 дней
  записывается с пометкой «Возможный дубль» (хэш ранней строки).
- **Таблица.** Пишем только новые строки и по названиям колонок. Свои колонки и «Статус»
  можно править: запуск их не трогает.
- **Состояние** (последний `message_id` по каналу): скрытый лист `_state` (Sheets) или
  `out/state.json` (CSV). Сначала пишутся строки, потом состояние.
- **Здоровье.** Если ни один канал не ответил, запуск завершается с ошибкой (код 2).

## GitHub Actions

- `CI`: ruff и pytest на каждый push.
- `Dump posts` (ручной запуск): проверяет t.me/s с серверов GitHub и выгружает сырые посты
  как артефакт `raw-posts`.

Секреты (Settings → Secrets and variables → Actions): `GOOGLE_SA_JSON`, `SHEET_ID`,
`ANTHROPIC_API_KEY` (с этапа 5).
